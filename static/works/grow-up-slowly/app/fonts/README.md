# Fonts

`wenkai-regular.woff2` and `wenkai-medium.woff2` are subsets of LXGW WenKai v1.530 (霞鹜文楷, https://github.com/lxgw/LxgwWenKai) by LXGW, licensed under the SIL Open Font License 1.1 (`OFL.txt`). They contain only the characters used in this MV.

To regenerate after changing the lyrics or titles: `sh scripts/subset-grow-up-slowly-font.sh <folder with the release TTFs>`.
