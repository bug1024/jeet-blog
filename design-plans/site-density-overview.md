# BUG1024 全站信息密度调整方案

Written against: `cb49e0e2d003b81128aac41440c86a821a44cdb4`

## 目标

让读者更快看到文章与作品。保留墨色、雾白、钢蓝、宋体标题、无大字封面的视觉语言，减少展示性空白和解释网站如何编排的文字。正文阅读宽度与行距不作为压缩对象。

## 三项执行计划

1. [内容入口与布局](01-content-density.md)：首页、文章列表、专题、标签、作品列表、关于页和文章标题区。
2. [界面文案减量](02-interface-copy.md)：删除重复说明，保留事实与必要提示。
3. [正文阅读节奏](03-reading-rhythm.md)：减少章节与文章收尾区域的空档。

## 页面目标结构

- 首页：紧凑介绍 → 最近写作 → 阅读专题 → 精选文章。作品仍由导航进入，遵循此前不放首页的决定。
- 文章列表：文章标题与篇数 → 按年份排列的文章，不附网站编排说明。
- 专题列表：专题标题 → 名称、篇数、简短内容摘要。
- 专题详情：名称与篇数 → 分组及文章；仅在有实际阅读限制时保留提醒。
- 标签：标签标题 → 标签与数量。
- 作品列表：作品标题 → 两列图片卡片，每项附类型、年份、名称和具体摘要。
- 关于：关于我 → 三座城市的时间轨迹与个人介绍，保留日记、工作、AI 写作等事实。
- 文章详情：标题、日期、标签、阅读时间与可选封面 → 正文 → 一组明确的后续阅读入口。

## 实施顺序

先执行文案减量，再调整内容布局，最后微调正文节奏。三个计划共同验收，避免删文案后仍保留原来的固定高度。

## 验收方式

桌面以 1440×900、1280×800，移动端以 390×844、360×800 检查。首页桌面首屏至少完整出现一条最近文章；移动首屏出现最近写作标题和第一篇文章标题。列表页首屏必须出现真实条目。长标题不得截断，正文不缩字，不靠降低行距提高密度。

所列像素值是首版实施目标，尚未经过浏览器测量。以首屏内容、标题换行和实际阅读结果验收，不为了数字一致破坏内容。

## 范围

只修改公共内容页面及界面文案。保留 URL、排序日期、草稿与隐藏机制、专题关系、封面文件、视觉档案和文章正文含义。绘本阅读器、地图、落日查看器、像素世界、钓鱼等作品内部体验不纳入本轮。

已实施公共页面布局、界面文案减量与阅读间距调整。保留独立作品内部布局，未提交或推送。
