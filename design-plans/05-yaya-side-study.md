# 三花猫侧影 · 第一稿

仅设计形象，暂不接入首页，也不改变现有 Logo。

- 安静坐着，朝左看，预留放在首页右侧、面向文字的使用方向。
- 墨色轮廓 `#111A21`，雾白毛色 `#F8FAF9`，低饱和橘色毛斑 `#CF9A61`。
- 橘色来自三花猫的毛色，不扩展为网站 UI 强调色；不把钢蓝画成猫的毛斑。
- 保留单侧眼睛、小鼻子和两根胡须，不加笑脸、腮红、饰品或背景。
- 使用 SVG，线条与色块可单独调整，不使用 AI 位图。
- 未提供丫丫照片，这一稿只确定图形语言，不宣称复刻她的外形。

后续先看形象是否符合预期，再决定花纹、线宽与首页实际显示尺寸，避免图案撑高首屏。
