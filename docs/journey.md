# 向北，再向南

作品地址为 `/works/journey/`。作品从1991年出生写起，以连续阅读的年月记录为主，地图随阅读阶段变化。

## 维护位置

- `data/works/journey.json` 保存九个生活阶段、停留时长、段落、文字记录出处及旅行附记。
- `layouts/works/journey.html` 渲染正文、章节目录、旅行附记、结尾回望及地图状态。
- `static/js/journey.js` 绘制示意地图，以原生页面滚动确定当前阶段，保留已经经过的主线。
- `static/works/journey/journey.css` 是作品独立样式。旧的整屏卡片样式已从全站 SCSS 移除。

作品采用统一纸色 `#F4F0E6`、水域 `#E0E7E1`、陆地 `#D2C8B5` 与墨色正文。按作者本次明确选择，朱砂 `#A34132` 用于作品的迁徙主线，这是独立作品内的用途，不更改主站钢蓝结构色或标志规则。普通地点使用灰蓝，关键地点加大节点。取消重复的编号、年份柱、停留年轮、经纬网及仿纸颗粒，仅保留章节年月与停留时长。

作品目录封面 `static/works/journey/cover-route.svg` 使用同一组真实坐标绘制朱砂迁徙线，包含厦门短暂停留和返回福州的顺序。它是代码绘制的地图示意，不是 AI 生成的文章封面，不添加虚构照片或视觉系列签名。

## 事实依据

乡村、学校、城市、时间段和所有旅行点沿用原始足迹数据，坐标未变。内容补充来自已公开的作者记录：

- `content/about.md`：2010—2016年在福州、北京七年、2023年到南京，2004年开始写日记。
- `content/posts/2016-12-12-past-two-years.md`：专业选择、最初的工作、离开福州的原因、到北京后转向 Java 的工作，以及当时留下的文字。
- `content/posts/2017-01-01-2016summary.md`：2016年11月底离开福州去北京。
- `content/posts/2026-07-18-why-i-restart.md`：2017年的博客记录、2020年6月后停更、2026年重新整理博客。

没有补写未经确认的房间、行李、家庭事件、照片或内心感受。年龄按1991年出生概算，未推断具体生日。厦门一个多月与福州工作阶段属于同年的不同经历，停留时长不做跨阶段求和。日记起始年份依据关于页，不伪装成当年的原始摘录。

## 阅读与交互

- 页面原生滚动，所有章节同时保留在正文中，没有滚轮锁定或整屏翻页。
- 桌面地图在左侧停驻；手机地图在顶部停驻，高度为225px到310px之间，正文自然滚动。
- 章节目录与返回起点使用真实锚点，可复制链接、键盘访问并直接进入某一章节。
- 旅行附记默认折叠，展开后点击某地可查看支线，再次点击可取消。选择不会自动闪烁或定时消失。
- 系统开启减少动态效果时，地图直接切换，锚点不平滑滚动。
- 页面正文由 Hugo 输出，不依赖 JavaScript 才能阅读。脚本和独立样式有内容版本参数。

地图保留原有的概略国土轮廓，比例尺为基于坐标的近似示意，没有生成未经测绘的地形。

