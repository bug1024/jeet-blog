# 75捞鱼互动作品

博客地址：`/works/75-fishing/`，入口自动出现在作品目录中。

## 维护位置

- `content/works/75-fishing.md`：作品信息与目录缩略图。
- `layouts/works/fishing.html`：保留博客页眉的作品模板。
- `static/works/75-fishing/app/`：Three.js 场景、样式、界面和依赖。
- `static/works/75-fishing/app/character.js`：75的独立程序化模型、贴合脸面的像素表情和双手握网动作。
- `static/works/75-fishing/cover.png`：来自75表情包项目的现有横幅。

场景在同源 iframe 内运行，隔离 Three.js 页面样式与 Meme 主题样式。博客页眉与导航继续使用全站品牌，场景页面设为 noindex，作品主地址由 Hugo 提供 canonical 与 sitemap。所有资源随 Hugo 构建发布，不依赖独立站点或运行时 CDN。

Three.js 固定为 0.180.0，本地依赖及许可证在 `app/vendor/`。这是一个纯静态作品，不需要增加 npm 构建步骤。此目录现在是博客中这一版场景的维护来源。

## 交互

拖动旋转、滚轮或双指缩放；点击75或“捞一下”挥网；点击水面惊鱼。水流、日光、暂停、重置视角及保存PNG按钮均可用。聚焦场景后，方向键旋转，空格暂停，Enter捞鱼，R重置。计数仅保留于当前页面，小鱼展示后放回溪流。系统开启减少动态效果时默认暂停。

```bash
node --check static/works/75-fishing/app/main.js
hugo --noBuildLock --gc --minify
python3 verify_urls.py
git diff --check
hugo server --bind 127.0.0.1 --port 1313
```

打开 `http://127.0.0.1:1313/works/75-fishing/`。

源码是程序化风格模型，水面、鱼群与捕捞使用视觉近似，没有流体模拟或真实网布物理。

人物按原表情包重做了收窄下颌的头部截面、后脑两侧的小短辫与碎刘海、深色背带及连体橙色涉水服。像素五官映射到有弧度的脸面上，眨眼和捞到鱼后的笑脸复用同一组表情纹理。页面版本包含人物模块，版本参数沿主模块传递到人物模块，避免更新后继续加载旧造型。

角色设定以作者补充为准：头发在后脑两侧绑成两个小小的短辫子，前额与耳边留碎发；橙色衣服从胸前贯通腰胯和两条裤腿，是整件穿入的连体背带服，不是分体上衣加裤子。

右下角控制面板支持收起与展开，手机端初始收起，保留小型“溪边设置”入口；展开后可以点击减号或按 Escape 收起。面板收起不影响旋转场景、点击75捞鱼、暂停与保存画面。

## 溪流材质与光照

`static/works/75-fishing/app/environment.js` 负责地形、水面、河岸、植被及材质，与人物模块分开维护。修改该文件会参与 Hugo 页面的版本计算，并通过版本参数加载。

- 河床、岸线植被和石块共用 `groundHeight(x, z)`，水道中部较深，岸边逐渐变浅；鱼保持在溪床之上。
- 水面以场景颜色与深度纹理实现轻量屏幕空间折射、深度吸收和视角相关的 Fresnel 反光；反射使用程序化天空近似，不是屏幕空间反射或流体模拟。
- 石块使用共享实例绘制，带程序化颗粒、随高度变化的干湿颜色和粗糙度，以及水下焦散近似；大石边缘有局部水流扰动。
- 草沿河岸高度与程序化斑块分布，叶片有弯曲和根部至尖端的色差。树冠改用实例叶片，保留稀疏花丛与轻微树叶摆动。
- 主光与环境补光重新平衡，沿用 ACES 和阴影贴图，未叠加 AO、景深或 Bloom。水面捕获与最终画面共用阴影结果。
- 手机端像素比上限为 1.5，水下捕获分辨率为绘制缓冲的 65%；桌面分别为 2 和 85%。手机默认收起控制面板的行为不变。

本轮在桌面与 390px 手机视口中验证场景加载、着色器编译、捞鱼计数、暂停、光照与水流滑杆、面板收起展开和画面导出。模拟手机视口不能代替实体手机的 GPU 性能测试。
